# Goonmoji

## 1.0 (2026-10-15)

First Goonmoji release: Emoji-Core + Emoji-Noto merged into one addon and modernized.

- Targets WoW: Midnight 12.1.5 (120105) and WoW Forever 1.60.1 (16001); the old Vanilla/Wrath/Cata TOCs are gone.
- New: SomethingAwful smiley pack (forum codes and categories), with animated smileys animating in
  chat, the keyboard and autocomplete. SA codes win over standard emoji with the same name.
- New: classic text smileys `:)` `:(` `:D` `;)` (toggle in settings).
- Noto Emoji updated to the Unicode 18 release (2026-09-24) and curated. Skin-tone, gender,
  direction and family variants fold into their base emoji. Country flags are rendered from the
  Noto flags font.
- Uses ChatFrameUtil instead of the deprecated ChatFrame_*/ChatEdit_* globals.
- The restriction handling now covers the new Map and Chat restriction types, and works on
  Forever too (it was Mainline-only before).
- Secret chat values are never touched.
- Fixed: the addon failed to load on non-English clients (missing default locale).
- Fixed: keyword autocomplete never scanned keywords (missing KeywordCount, wrong loop bound).
- Fixed: the Communities chat box hook called a non-existent EventRegistry method.
- Fixed: emoji keyboard insertion used ChatEdit_GetActiveWindow without calling it.
- Fixed: boolean settings could never be saved as false.
- Emoji data is now generated by tools/build.py (0.8 MB instead of 13 MB of Lua).
- The SavedVariables name is now GoonmojiSaved, so Emoji-Core settings don't carry over.
- English only; the zhCN data was dropped. Non-English clients load with English strings.
